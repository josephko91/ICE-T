# docs/

- **`dataset-changelog.md`** — curated, reverse-chronological log of changes
  that affect the parquet's rows/columns/coverage. Start here if you want to
  know what changed and when.
- **`decisions/`** — internal engineering decision log: investigation write-ups
  for specific bugs/design choices as they happened during development.
- **`reports/`** — internal diagnostic/analysis reports generated during
  development (coverage breakdowns, validation runs, survey notes).

`decisions/` and `reports/` are development history, not required reading to
use the dataset — see the top-level `README.md` for the beta-facing overview,
and `CLAUDE.md` for the full project reference (schema, conventions, known
issues) used to drive this repo's AI-assisted development.
